How to read this & what to try

The model. Every round each person may send invites to others. The invitee checks their memory (plus gossip they've heard) and accepts only if the inviter looks trustworthy enough. Accepted invites become one prisoner's-dilemma game: both secretly choose collaborate or betray.

  • Network: node color = strategy, node size = wealth. Green edge = mutual cooperation, orange = one betrayed, red = mutual betrayal.
  • People learn two ways: strategies react to each partner's history (e.g. tit-for-tat retaliates), and people copy the strategy of the most successful person they know about (social learning rate).
  • Gossip spreads second-hand reports; trust sets how much weight they carry vs. direct experience.

Things to try:

  • Set Memory length and Gossip rate to 0 ("Amnesia" preset) — can cooperation survive when nobody remembers anything?
  • Raise Temptation T — at what point does betrayal become irresistible?
  • Crank Gossip rate + Accept threshold ("Panopticon") — watch defectors get frozen out of all social life.
  • Compare Generous TFT vs Grim populations: which world forgives, which never forgets?
  • Raise Social learning rate — fast imitation spreads the winning strategy like a fashion.
